## Evidence and generation

All numeric outcomes use `code/simulation/results/core/`. Main tables reference the retained `runs.json`, `condition-summary.csv` and `paired-contrasts.csv`; warning and reservation numbers use `warning-summary.json` and `mechanism-diagnostics.csv`. Communication and component appendix tables additionally use `runs.json` and `component-resources.csv`, keeping recorded in-run timers distinct from repeated saved-input benchmarks. Six supplement tables are regenerated by `code/simulation/scripts/build_report.py`; `generated/table-provenance.json` records input/output and generator hashes. It writes generated tables only and must not overwrite collaboratively edited text.

Pooled policy means describe six equally sized conditions. They are not a new pooled inferential test. Idle sums both boats before taking the run mean. Mean coverage includes completed and incomplete missions. Outage durations pool observed episodes within each condition and may be truncated at the end. Local gap averages both boats' per-run scheduled-sample means; stopping gap is a separate quantity. S1 transmits no messages, so its radio availability is only the channel sampled along its route.

The new explanatory diagnostic checks all 180 S2 raw logs: the last movement of either boat occurs between 265 and 520 s, before the earliest possible slowdown at 600 s. This is not an additional primary endpoint or a protocol change. Reproduce from `code/simulation` with the following read-only Python:

```python
import gzip
import json
from pathlib import Path

root = Path("results/core")
rows = json.loads((root / "runs.json").read_text())
last_motion = []
for row in rows:
    if row["policy"] != "S2":
        continue
    name = f"{row['seed']}-{int(row['slowdown'])}-{row['fade_length']}-S2.jsonl.gz"
    previous, last = None, 0
    with gzip.open(root / "raw" / name, "rt") as stream:
        for line in stream:
            event = json.loads(line)
            if event["event"] == "tick":
                if previous is not None and event["xy"] != previous:
                    last = event["t"]
                previous = event["xy"]
    last_motion.append(last)
assert len(last_motion) == 180
assert (min(last_motion), max(last_motion)) == (265, 520)
```
