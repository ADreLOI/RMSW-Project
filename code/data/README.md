# Data and provenance

No research data have been generated yet. Keep bulk raw datasets and experiment logs outside the Overleaf-linked repository; `data/raw/` and `results/raw/` are ignored.

For each dataset or simulation run, record the source or generator, access date, license, units, parameter configuration, random seeds, code revision, preprocessing, missing values and exclusions. Preserve failed and incomplete runs.

Do not commit meeting recordings, transcripts, credentials or private participant information. Keep only redistribution-permitted material. Small curated result summaries and publication figures can be versioned once linked to their provenance.
